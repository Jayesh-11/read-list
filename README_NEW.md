## WIP : Just playing around with Svelte

I used to manage all these links in a markdown file, while easy to manage, there were some problems, also there was no scaling issue, as realistically there wouldn't be >10000+ links.

1. How do you search what you need from over 300+ links
2. How do you share these links easily
3. I don't want to go to github to share link
4. I wanted notes based search and tag based search
5. Share the whole list with someone
6. Easily add to the list
7. Aesthetics

Also I wanted to test drive Svelte, so learnt via building, and this was the outcome, **intentionally kept it simple**, fork, star, build your own read list.

{
  "[svelte]": {
    "editor.defaultFormatter": "svelte.svelte-vscode"

}
